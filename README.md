# Барилгын компанийн танилцуулга

`index.html` файлыг браузераар нээгээд үзнэ. Нэмэлт програм суулгах шаардлагагүй.

- `index.html` — Монгол хэл дээрх агуулга, компанийн мэдээлэл.
- `style.css` — өнгө, фонт, компьютер болон гар утасны загвар.
- `script.js` — гар утасны цэс, төслийн шүүлтүүр, хүсэлт татах үйлдэл.

MNG Констракшн нэр, төслүүд, тоон үзүүлэлтүүд нь жишээ мэдээлэл. Бодитоор ашиглахын өмнө өөрийн компанийн мэдээлэл, төслийн зураг, холбоо барих хаягаар солино.

Зургууд Unsplash, фонт Google Fonts-оос ачаалагдах тул интернэт шаардлагатай. Фонт ачаалагдахгүй үед системийн фонт ашиглана.

Хүсэлтийн маягт мэдээллийг сервер рүү илгээхгүй. Бөглөсөн хүсэлтийг хэрэглэгчийн төхөөрөмжид UTF-8 текст файл болгон татна. Имэйлээр автоматаар илгээх бол сервер эсвэл маягтын үйлчилгээ нэмж холбох шаардлагатай.

Шалгалт: HTML-ийн давхардсан ID, дотоод холбоос, CSS болон JavaScript файлын бүрдлийг шалгасан. Энэ орчинд Node.js байхгүй тул JavaScript-ийн командын шалгалт хийгдээгүй; браузерын харагдац болон үйлдлийг автоматаар шалгаагүй.
